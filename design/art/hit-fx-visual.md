# 美术 · 命中冲击视觉语言（Hit-Impact Visual Language）

> **文档定位**：本文件是 `design/gdd/hit-feedback.md`（文策渊，确定性 / 按武器分级 / 皮肤身份色的行为与参数规格）的**视觉语言伴侣**。前者规定「每次命中出什么、出多少、什么色相、什么档位」；本文件只回答一个问题：**命中冲击「长什么样」**——构成元素、形状与拖尾、取色与亮度、分级梯度，以及与死亡爆炸的视觉层级。
>
> **状态**：美术规格 v1　|　**作者**：林绘澄（art-director）　|　**关联文档**：`design/gdd/hit-feedback.md`（分级 / 色相 / 尺寸区间 / 约束的唯一数据源，本文不再重复其参数，只引用对齐）
>
> **红线（与 hit-feedback.md 一致）**：命中冲击**绝不**是「几颗纯填充小圆」；**绝不**用敌机色相 `en.hue`；**绝不**与死亡爆炸同尺寸同色温；渲染层**零 RNG**（S16）。

---

## 0. 一句话总纲

**命中冲击 = 从一个接触点确定性地迸出的「方向性碎片条 + 近白闪核（+ 可选微冲击环）」。它读起来是一记锋利的「tick」，而不是一个圆、也不是一次爆。**

当前实现把命中火花画成 6 颗纯填充小圆（`game.js` 粒子绘制层），被用户判为「太水、就一个圈」。本文件定义取代纯圆的视觉词汇。

---

## 1. 视觉词汇（Visual Vocabulary）

一次合格命中冲击由以下元素构成。**闪核与碎片条为必选；微冲击环为 L 档可选。**

### 1.1 ① 方向性碎片迸射条（Streaks）—— 取代「圆」

- **不再是圆**：每颗粒子是一条**细长、带拖尾衰减的碎片条**（shard / streak），而非等径圆点。
- **出生**：从命中点（`b.x, b.y`）沿确定性方向（见 §2.3）向外迸出，位置锚定在**接触点**而非敌机中心。
- **形态**：头亮尾淡的锥形/纺锤形条；近端（靠接触点）更亮更窄，远端更淡更细，呈撕裂感而非球状。
- **数量**：沿用 hit-feedback §3 的 `N`（S=4 / M=6 / L=8，硬上限 ≤10）。

### 1.2 ② 明亮闪核（Flash Core）—— 命中的「咬到了」

- 接触点正中的一枚**近白高亮小核**（亮度高、尺寸小、寿命极短），作为伤害确认的核心视觉锤。
- 色相：**近白（微染武器色）**，不参与色温偏移；尺寸为 `sz₀` 的白芯子区间（hit-feedback §6：`sz₀·0.42` ∈ [1.7, 3.8]px）。
- 即使碎片条是武器色，闪核也必须是**近白高亮**——这是「tick」与背景割裂的关键。

### 1.3 ③ 可选微冲击环（Micro Shockwave Ring）—— 仅 L 档

- 一次性向外扩散的**薄环**（一道，非多层），借 `rings` 池（hit-feedback §8.2）。
- 语义：重击的「分量感」，不是爆炸。薄、淡、单次、半径受限（`maxR` ∈ [18, 30]px，命中冲击总外扩 ≤ 60px）。
- **与 laser 的扁平冲击圆盘区分**：laser 的扁盘是弹型特性（hit-feedback §3.4），走 `rings` 池出薄环充当圆盘边缘；本微环是 L 档**通用**分量，二者叠加时仍属「重击 tick + 环爆 boom」层次，不喧宾夺主。

### 1.4 视觉词汇示意（ASCII）

```
           命中冲击（M 档，武器色 = 青）
                ____
           _-'    '-_          ← 碎片条：头亮尾淡、细长、向外
        -'   ·核心·   '-        · = 近白闪核（最亮最小）
       |   (近白高亮)   |       ← 环：仅 L 档才有，( ) 表示虚扩
        '-_        _-'
           '-____-'

   死亡爆炸 explode()（对照，敌机色 + 暖色温梯度，19 颗高密度）
      (((  ✸✸✸  )))        ← 多层、高密度、大外扩、火芯 + 高速火花
     ( ✸✸✸✸✸✸✸ )          读感是「boom」，远重于上者
      (((  ✸✸✸  )))
```

## 2. 形状与拖尾（Shape & Tail）

### 2.1 长宽比（Aspect Ratio）

- 碎片条**长度 : 宽度 ≈ 4:1 ~ 7:1**（短档 S 偏 4:1，重档 L 偏 7:1）。
- 宽度跟随 `sz₀`（hit-feedback §6：4–9px），长度 ≈ 宽 × 长宽比，即 S≈16–35px、M≈20–45px、L≈26–63px（须受总外扩 ≤ 60px 与 ≯1.6× 接触半径约束夹取）。
- 绝不允许接近 1:1（那会退化回「圆」）。

### 2.2 拖尾衰减（Tail Attenuation）

- **亮度沿条长单调递减**：近端（接触点侧）≈ 闪核亮度，远端衰减到约 25–40% 后淡出。
- **宽度沿条长收敛**：近端略宽、远端收尖（纺锤/锥形），强化「迸射」而非「漂浮」。
- 实现建议（供工程参考，非本文件强制）：用沿条长的 alpha/亮度渐变 + 端宽收窄描述一条 streak；不必逐粒子 new 几何，复用 `particles` 池（hit-feedback §8.2）。

### 2.3 是否受武器速度方向影响（Directionality）

**是，且这是「方向性碎片条」命名的核心。**

- **基础迸射**：仍以接触点为中心向四周确定性散开（hit-feedback §8.1 的确定性相位 `phase = (ei × G) mod 2π`，第 k 颗 `a_k = (k/N)·2π + phase`），保证零 RNG。
- **速度偏置**：在基础角度上叠加一个**沿子弹飞行方向的扇形偏移**——碎片条整体「朝子弹来向的反侧溅开」，使玩家读出「这一发是从这个方向打进来的」。偏置强度按武器档位：
  - **直射/高 sp 武器**（dot / homing / laser）：偏置强，读「穿透溅射」。
  - **霰射 fan**：每颗弹丸独立轻击（S 档），偏置随各自弹道，整体读成一片细密 tick。
  - **arc 弧带**：粒子可带轻微切向偏移，读「甩出去的光鞭」触感（角度仍确定性，禁 RNG）。
- 偏置**不得**改变「向四周散开」的基本语义，仅做方向加权，避免冲击变成单向光束而丢失位置确认。

## 3. 颜色与色相（Color & Hue）

### 3.1 取色规则（对齐 hit-feedback §4）

- 命中冲击**一律用武器/皮肤色相 `b.hue` 原值上色**，**绝不用敌机色相 `en.hue`**。
- 色相来源：`DJFE.weaponOf(DJFE.skins.currentId()).hue`（须工程补齐 `hue` 字段，见 hit-feedback §9 未决 1）。
- 命中冲击色相 = `b.hue` **原值、不做色温偏移**（保持「冷/平」的 tick 感，与死亡爆炸的暖色温梯度区分，见 §5）。

### 3.2 各皮肤打击色（Hue）取值表（引用 hit-feedback §4.2）

| 皮肤 | 打击色 hue | 色带落点 |
|---|---|---|
| `cyan_knight` | **190** | 玩家色带 175–200 正中（识别「这是我」的锚点） |
| `crimson_falcon` | **354** | 机体暖红身份色（非危险带） |
| `emerald` | **152** | 独立绿身份色 |
| `violet` | **259** | 独立紫身份色 |
| `stealth` | **194** | 玩家色带；暗机体靠它发 rim light |
| `golden` | **44** | 弹舱/炮塔发光位（玩家弹，非道具） |

### 3.3 危险带避让（对齐 hit-feedback §4.3）

- 敌弹危险带为 **hue 12–24**。上表六色（190/354/152/259/194/44）**均不在危险带内**；自定义皮肤若引入新 hue，须校验落点避开 12–24，防止把「我的命中火花」误读成「敌弹」。
- 闪核虽近白，但其微染的武器色仍须满足同上避让。

### 3.4 闪核亮度

- 闪核 = **近白高亮**（亮度接近满、饱和度低），可在白中微染 `b.hue` 以与武器呼应，但主体必须读成「白」。这是命中冲击里最亮的元素，也是与背景割裂的视觉锤。

## 4. 亮度 / 尺寸梯度（按冲击力分级 S / M / L）

> 分级维度与档位定义见 hit-feedback §3；尺寸区间见 hit-feedback §6。下表把「视觉观感」与那些参数对齐，给出**亮度与尺寸的建议区间**，目标：太小看不见（「太水」）、太大刺眼糊成一团（「太大」）都避免。

| 档 | 适用（hit-feedback §3.3） | 碎片条长度 [px] | 闪核亮度 | 整体亮度观感 | 微冲击环 |
|---|---|---|---|---|---|
| **S · 轻击** | 低单发伤 / 多弹丸（每颗轻） | 16 – 28 | 高（近白） | 克制、清脆的小 tick | 否 |
| **M · 标准** | 基线武器（dmg≈1.0） | 20 – 40 | 高（近白） | 明确但不抢戏的标准 tick | 可选（淡，maxR 12–18） |
| **L · 重击** | 高单发伤 / 穿透 / 大弹 | 26 – 60* | 极高（近白，短寿） | 厚重、有分量的重 tick | **是（maxR 18–30）** |

`*` L 档长度受 hit-feedback §6 双重约束夹取：**总外扩（粒子飞散可达半径 + 环）≤ 60px，且 ≯ 1.6 × 受击敌机接触半径**——守 P2 可读性，不得吞掉敌机轮廓。

**亮度梯度原则**：
- 闪核恒为最亮（近白）；碎片条亮度 = 武器色在高明度下的呈现，**随档位微调**（L 比 S 更亮、更不透明），但整体都明显**低于**死亡爆炸的火芯亮度（见 §5）。
- 避免纯白铺满：闪核小而集中，碎片条头亮尾淡，确保「锐利」而非「糊白」。

## 5. 与死亡爆炸 `explode()` 的视觉层级（Visual Hierarchy）

> 分层规则见 hit-feedback §5 / §7。本文件从**视觉观感**维度复述层级要点，确保玩家一眼区分「命中（tick）」与「击杀（boom）」。

| 维度 | 命中冲击（本文件） | 死亡爆炸 `explode()` |
|---|---|---|
| **触发语义** | 每一次命中（含致命前的那一帧） | 敌机 `hp≤0` 一次性 |
| **形状** | 方向性碎片条 + 近白闪核（+ 可选薄环） | 多层高速火花 + 火芯，**非条状** |
| **粒子数 / 密度** | ≤10，稀疏定向 | 18 + 1，高密度爆散 |
| **尺寸 / 外扩** | sz₀ 4–9px，总外扩 ≤ 60px（明显小） | 火芯 + 高速火花，外扩远大于冲击 |
| **色温 / 色相** | `b.hue` **原值、无偏移**（冷/平 tick） | 内暖 `hue+28`、中 `hue+6`、外沉 `hue-14`（温度梯度） |
| **亮度** | 闪核近白但克制，碎片条中亮 | 火芯极亮 + 暖色温，整体更「炸」 |
| **寿命** | 短（0.55–0.90 步），转瞬即逝 | 较长，分层拉开余韵 |

**层级区分要点（视觉口诀）**：
1. **尺寸**：冲击 ≪ 爆炸——冲击是贴在敌机身上的小火花，爆炸是吞掉敌机的数倍大爆。
2. **密度**：冲击稀疏定向（≤10 条），爆炸密集爆散（19 颗）。
3. **色温**：冲击是武器色「无偏移的平 tick」；爆炸是「内暖外沉」的温度梯度。致命时二者相邻出现（冲击武器色 + 爆炸敌机色 + 温度差），玩家仍清晰读到 **tick → boom** 而非双重 boom。
4. **寿命**：冲击一闪即过，爆炸有余韵——靠寿命差再拉一层区分。

> 死亡爆炸**保持 `en.hue`（敌机色）不变**（hit-feedback §7 有意设计）：致命时「我的武器色 tick」叠加「它的敌机色 boom」，反而强化「我打中 + 它死」的双重归因，不冲突。

## 6. 实现口径提示（美术视角，非代码）

- **渲染层零 RNG（S16）**：碎片条角度须由确定性源推导（hit-feedback §8.1 的 `(ei × G)` 黄金角相位），**禁止任何 `Math.random()`**。
- **对象池零扩容（S18）**：碎片条/闪核复用既有 `particles` 池（cap 3000）；微冲击环借 `rings` 池（cap 96），且仅当 `rings.length < RING_FX_BUDGET(80)` 时才出环，超出则只结算冲击粒子、跳过环。
- **尺寸与寿命解耦**：现行 `sz = 1.6 + 4.2·life` 把尺寸绑死在寿命上（「太水」根因之一），建议工程给粒子新增 `baseSz` 使尺寸稳定可控（hit-feedback §9 未决 4）；解耦前用 `life` 临时口径逼近，但须守住 §4 的尺寸区间。
- **不做的事**：不改 `src/game.js` 命中逻辑、不改 `render3d.js` 取纹理契约、不动任何伤害/判定数值——本文件只定义「长什么样」。

## 7. 验收自检（美术侧）

- [ ] 命中冲击中**看不到任何纯填充圆点**（全部为细长碎片条 + 闪核）。
- [ ] 闪核为**近白高亮**，是冲击里最亮、最小的元素。
- [ ] 碎片条**头亮尾淡、带长宽比 ≥ 4:1**，并从接触点向外确定性散开。
- [ ] 颜色 = **当前皮肤 `b.hue` 原值**，非敌机色；六色均避开危险带 12–24。
- [ ] 任意档位下，命中冲击尺寸/密度/色温**明显弱于**同屏死亡爆炸，玩家能区分 tick 与 boom。
- [ ] 边缘 8px 内无残留背景；闪核/碎片条不盖过敌机轮廓（守 P2 可读性）。
